# Verification record

The migration includes executable contracts for state replay, raw vectors, rejection thresholds, full integer spans, extreme floating bounds, string validation, shuffle preservation, exact weighted intervals and platform-source boundaries. The complete verification command is `pwsh -File tools/Verify.ps1`.

Run-specific results and archive hashes are written under ignored `artifacts/verification-*` directories. CI artifacts retain the equivalent evidence. No published or remote verification is implied by this source document; the release manifest records those states separately.
