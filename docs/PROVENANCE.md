# Provenance

This repository continues the public history of https://github.com/Ben-Scr/RandomCS at `8d2a40f680e26c1bf235d72ca59dede9c6e59738` on `master`. The source package is RandomCS 1.0.2, originally targeting .NET 9. Existing repositories, tags and published packages are unchanged. `MIGRATION.md` maps every old public type and method group to its replacement.

The original `LICENSE.txt` is retained byte-for-byte. This is the original attribution license, not an MIT relicense. Created by Ben Schneider — https://github.com/Ben-Scr

The xorshift64* transition is retained from the source. Its mathematical basis is credited in `ALGORITHM.md`. Secure entropy and secure integer sampling use .NET platform APIs. No third-party runtime dependency is included; the pinned test framework is development-only.

`branding/BenScr_Icon_Master.png` is the unchanged original BenScr icon (RGBA PNG, 1254 × 1254, 795819 bytes), SHA-256 `a5dcabceb766e13c1840a95130ee98a458e12e3713fd9b07f3ceae75a1f5b993`. The same bytes are embedded as `icon.png` in the package. Legacy source icons remain historical assets and are not packed. No recoloring, resizing or substitute logo is used.
